# Landing site publication

The landing site source is in the separate coordinare-landing repository. Its owner must serve the
repository root llms.txt unchanged at the site's `/llms.txt` and add the prompt
below with a link to the setup guide. The absolute GitHub links in llms.txt work
without a documentation site build. This file is publication copy, not evidence
that the site has been updated. Apply and visually verify the accompanying site
change in the landing repository before publication.
