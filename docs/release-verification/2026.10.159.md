Suggested clarification: explicitly include OpenAI-compatible self-hosted endpoints among cases where model enumeration can be skipped. No workaround was attempted; skip is permitted by the report semantics. This check does not establish that `glm-5.3-flash` is actually served.

The guide does not explain that a 404 response can satisfy reachability. Suggested clarification: distinguish an HTTP response from successful API-route or model validation. This was a nonblocking observation, not a connection warning or failure. The exact approved `/v1` URL was retained. No URL guessing, route changes, additional model requests, or output generation were attempted.

The install snippet defaults to latest and the answers example defaults to `full`, but the surrounding guide explicitly explains both overrides: "For a pinned install, download `releases/download/TAG/install.sh` instead and pass `--version TAG`" and "choose `base` for roughly 4 GiB".
