The one-paragraph model

01What is it?

A coordinare (one daemon) conducts several symphonies (projects). For each card it dispatches a sequence of performers (one per lifecycle role). Each performer runs an agent harness (a CLI) in a container with the project's cached environment, talking to a model — frontier (Claude) or local (gpt-oss, qwen). When local, a shim normalizes its output to frontier-grade. Gates enforce CI, security & human approval.

🎼 coordinare = the daemon 🎻 symphony = a project 🎤 performer = an agent 🛠 harness = the CLI it runs 🧩 shim = local→frontier parity
Why it exists

02Three hard problems, three answers

① One shot isn't enough

Real changes need plan → build → review → test → fix → merge.

→ an explicit lifecycle with gates, bounces & bounded retries.

② Agents need a real env

Tests need the toolchain, a DB, services.

→ a per-project env-cache mounted into every performer; services start on activation.

③ Local models ≠ frontier

They leak reasoning, mangle tool calls, emit bad JSON, wrong wire format.

→ a transparent shim + normalizers so stock harnesses just work.

Coordinare is, in essence, the accumulated answer to these three.

The big picture

03Five layers

① Coordinare — one daemon · LangGraph workflow · poll → dispatch → monitor → gate → merge
② Symphonies — N projects, each = a GitHub board + repo + config
③ Performers — per card, per role: architect · implementer · reviewer · security · qa · tech_writer · closer
④ Agent harnesses — claude_code · codex · opencode · junie · pi · hermes · openclaw (CLIs in containers)
⑤ Models — frontier (Claude) direct · local (gpt-oss / qwen / glm) through a shim
Orchestration flow

04How a card moves

Backlog→ TODO→ IN PROGRESS→ IN REVIEW→ DONE
architect→assess→ implement→review→ security→qa→ document→close
  • Sequential — a stage starts only when the prior one succeeds.
  • CI bounce → back to the implementer with the failing checks.
  • Infra failure → parked in BLOCKED + operator notified (not bounced).
  • Only humans approve the final merge — bots may comment, never approve.

The centerpiece

07Shims: making local models frontier-grade

A stock harness expects a frontier model. A local model breaks those expectations. A shim — a loopback reverse-proxy the harness's provider URL is repointed to — forwards requests verbatim and repairs responses. The harness is unmodified.

harness CLI→ SHIM (127.0.0.1)
route · normalize · translate→ local model
Ollama / LiteLLM
raw: reasoning leak · harmony tool-call leak · bad JSON · wrong wire ⇒ repaired: clean tool calls · valid JSON · right wire format
Routing

08Strategies & normalizers

reroute

Repoint the harness at a clean upstream. No shim, no rewriting.

normalize

Loopback shim repairs the response via normalizers.

translate

+ wire translation: Anthropic /v1/messages ⇄ OpenAI /v1/chat/completions (spec 084).

Normalizers (pure, fail-open repairs)

keyrepairs
harmony_tool_callsgpt-oss "harmony" channel leaking as text → reassembled into a real tool call
strip_reasoningthinking / reasoning_content leaking into the answer (promote if reasoning-only)
strip_control_charsunescaped control bytes that break the JSON parser (stripped pre-parse)

Chosen per (backend, model) in routing.yaml; gated by a startup health probe (tool_call | completion).

Environment cache

10A real place to build & test

Build the project's dev environment once, cache it on the host, mount it into every performer at /devenv (rw for bootstrap, ro for everyone else).

profile sourced on every shell: extract native libs → LD_LIBRARY_PATH, source activate.sh, then start services.

Services @ activation

Performer-owned

coordinare_manages_services=false by default (spec 116) — the performer owns env setup.

Safety

11Gates contain failure

CI gate 075/090

pass → advance · hold → wait · bounce → back to implementer · escalate → BLOCKED. Classifies introduced vs inherited vs flake vs env_blocked.

Env-blocked 095/118

Infra failures (artifact quota, runner perms) → HOLD + notify, never bounce a blameless implementer.

Baseline-repair 090

Refuse to merge onto a red base; bounded autonomous repair of inherited failures (audited, never auto-merges).

Resilience 098/119

Transient & malformed_output errors → bounded retry, not instant block. A bad roll from a stochastic model self-corrects.

…and the final gate: a human approves before merge.
