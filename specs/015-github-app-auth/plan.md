# Implementation Plan: GitHub App Auth, Polling Config & Webhooks

**Branch**: `015-github-app-auth` | **Date**: 2026-03-12 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/015-github-app-auth/spec.md`

## Summary

Add dual GitHub auth modes (PAT default, GitHub App optional) with automatic JWT generation and installation token refresh; make polling interval configurable including disable (`poll_interval_seconds: 0`); add an optional webhook endpoint that wakes the daemon cycle immediately on valid signed events. All modes expose an identical `GitHubAuth.get_token()` interface so no graph node or performer code changes.

**Status**: Complete — see [research.md](research.md)

Key decisions:
1. **JWT library**: `PyJWT[crypto]>=2.8` — standard, maintained, simple RS256 API
2. **HMAC verification**: stdlib `hmac` + `hashlib` — zero new dependencies
3. **Daemon signalling**: `asyncio.Event` (`_webhook_trigger`); `asyncio.wait_for` pattern replaces bare `await sleep(N)`
4. **Config migration**: `github_token` → optional; `poll_interval_seconds` `ge=10` → `ge=0`; new `github_auth`, `github_app_id`, `github_private_key_path`, `github_installation_id`, `webhooks` fields

## Phase 1: Design

**Status**: Complete — see [data-model.md](data-model.md), [contracts/](contracts/), [quickstart.md](quickstart.md)

### Entities

- **`GitHubAuth`** (Protocol) — `async get_token() -> str`
- **`PatAuth`** — static token; raises at construction if empty
- **`AppAuth`** — JWT + installation token exchange; `asyncio.Lock`-protected refresh; 5-minute expiry buffer
- **`PollingConfig`** — `interval_seconds: int` (0 = disabled)
- **`WebhookConfig`** — `enabled`, `secret`, `path`

### Key implementation notes

#### `AppAuth.get_token()` flow
1. Acquire lock (asyncio.Lock, created lazily on first call)
2. Double-check: if still valid, release lock and return cached token
3. Generate JWT: `iss=str(app_id)`, `iat=now-60`, `exp=now+600`, `alg=RS256`
4. `POST /app/installations/{id}/access_tokens` with `Authorization: Bearer <jwt>`
5. Parse `token` and `expires_at` from response; convert `expires_at` to monotonic seconds
6. Cache both; release lock; return token

#### Daemon loop replacement
Replace both `await self._sleep(self._poll_interval_seconds)` calls in `daemon.py` with `await wait_for_next_cycle(...)` from the contracts module.

```python
# poll > 0: wake on webhook OR timer
with contextlib.suppress(asyncio.TimeoutError):
    await asyncio.wait_for(self._webhook_trigger.wait(), float(self._poll_interval_seconds))
self._webhook_trigger.clear()

# poll == 0: block until webhook fires
done, _ = await asyncio.wait(
    {asyncio.ensure_future(self._webhook_trigger.wait()),
     asyncio.ensure_future(self._stop_event.wait())},
    return_when=asyncio.FIRST_COMPLETED,
)
self._webhook_trigger.clear()
```

#### `GitHubService` token rotation
Add `async def _current_token(self) -> str` that calls `self._auth.get_token()`. The GQL `AIOHTTPTransport` bakes the `Authorization` header at construction. To handle token rotation, compare the result of `_current_token()` against `self._last_token`; rebuild `self._client` only when the token changes. Since tokens are valid for ~55 minutes, rebuilds are rare (<2 per hour).

#### Webhook endpoint (FastAPI)
```python
@app.post(config.webhooks.path)
async def github_webhook(request: Request) -> JSONResponse:
    body = await request.body()
    sig  = request.headers.get("X-Hub-Signature-256")
    if not verify_github_signature(body, secret, sig):
        logger.warning("webhook_signature_invalid", path=request.url.path)
        return JSONResponse({"error": "invalid signature"}, status_code=401)
    webhook_trigger.set()
    return JSONResponse({"status": "ok"})
```

#### Startup validation sequence
In `coordinare.py` / `__main__.py`, after loading `ProjectConfiguration`:
1. Call `validate_auth_config(config)` — raises `SystemExit` with actionable message on failure
2. Construct `GitHubAuth` via `build_auth(config)`
3. If `config.webhooks.enabled`: register route on dashboard app before starting uvicorn
4. If `config.poll_interval_seconds == 0` and not `config.webhooks.enabled`: log `WARNING` then continue
