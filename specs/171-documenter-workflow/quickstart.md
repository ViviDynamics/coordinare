# Quickstart: Documenter Workflow

## Enable

```yaml
performers:
  tech_writer:
    workflow: documenter
    workflow_env:
      DOC_PLAN_CAP: "8"
```

Remove the `workflow` line to restore the prose plan-then-write path exactly.

## What the wiki looks like

- `docs/wiki/README.md`: generated by code in the llms.txt shape. One H1, a blockquote summary, H2 sections `Start here`, `Architecture`, `How to`, `Reference`, `Decisions`, `Optional`, each entry `- [Title](page.md): one line`. Every page linked exactly once.
- Section pages: frontmatter `kind: explanation | how-to | reference | decision` and that kind's headings (explanation: What it is, How it fits, Why it is this way, Where to change it; how-to: Goal, Prerequisites, Steps, Verify; reference: a table or list with a cited path per entry; decision: Context, Decision, Consequences, Status). Every claim cites a path that exists.
- `docs/wiki/decisions/<slug>.md`: one ADR per decision.
- `AGENTS.md` and `CLAUDE.md`: a pointer section between `<!-- coordinare:wiki-pointer:start -->` and `<!-- coordinare:wiki-pointer:end -->`, under 40 lines, naming the entrypoint and the three pages to read first.

## Run the stubbed eval

```bash
PYTHONPATH=src:agent/performer/src .venv/bin/pytest tests/eval/documenter_scenarios -q
PYTHONPATH=src:agent/performer/src .venv/bin/python -m coordinare.eval.documenter_scenarios
```

Six fixtures on generated repositories: `trivial` (empty plan, no model call, no commit), `feature` (brief page plus the architecture page plus the README, one commit), `shape` (essay README, how-to without Verify, changelog heading: all dropped, README regenerated), `hallucinated_citation` (a page citing a missing module is dropped, the rest commit), `init` (skeleton capped at 8, pointers added), `pointers` (stale section replaced between markers, rest byte for byte).

## Run live inside the performer image

```bash
set -a && source .env && set +a
docker run --rm --network host --entrypoint python \
  -e PYTHONPATH=/work/src:/work/agent/performer/src:/work \
  -e LITELLM_BASE_URL -e LITELLM_MASTER_KEY -e COORDINARE_INFERENCE_MODEL \
  -v "$PWD":/work:ro -w /work coordinare-performer:full \
  -m coordinare.eval.documenter_scenarios --live --only feature
```

Live mode uses the gateway model and a temporary git repository; commits land in that repository only (no push, no PR).

## Verification checklist

- [ ] Six fixtures pass in CI; `feature` and `init` pass live.
- [ ] Every gate rule test fails under its named mutation (table in the PR).
- [ ] Without the flag, main.py's documenting path is unchanged byte for byte.
- [ ] Both trees green in separate invocations; coverage gate holds.
