# Implementation Plan: Performer Event Stream

**Branch**: `014-performer-event-stream` | **Date**: 2026-03-13 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/014-performer-event-stream/spec.md`

## Summary

Add a unified real-time activity feed surfacing what each AI coding agent does while
a card is in progress. Events from each backend's native stream are normalised into a
common `BackendEvent` model, accumulated in a rolling buffer, returned on every
`check_status` poll, and displayed in the dashboard as a live scrolling timeline.

**Codebase audit reveals**: the vast majority of this feature is already implemented
and tested. The only remaining work is **secret redaction** on `BackendEvent.detail`
and **dashboard coverage** improvements.

**Language/Version**: Python 3.12+
**Primary Dependencies**: all existing — `pydantic>=2.9`, `structlog>=24.1`, `asyncio` (stdlib), `re` (stdlib)
**Storage**: in-memory rolling buffers only — `deque(maxlen=200)` per backend, `list[-100:]` in coordinare state
**New Backends**: `ClaudeCodeBackend` and `CodexBackend` — both already implemented and tested

**Target Platform**: Linux/macOS server daemon
**Performance Goals**: `drain_events()` synchronous in-memory; adds <1 ms to each status response
**Constraints**: No new dependencies; no new wire protocol message types; additive (missing `drain_events()` is a no-op)
**Scale/Scope**: Per-session in-memory buffers; single coordinare instance

### Redaction implementation (the only new code)

In `agent/performer/src/performer/models.py`:

```python
_SECRET_PATTERNS: list[re.Pattern[str]] = [
    re.compile(r"github_pat_[A-Za-z0-9_]{82,}"),   # fine-grained PAT
    re.compile(r"ghp_[A-Za-z0-9]{36}"),             # classic PAT
    re.compile(r"gho_[A-Za-z0-9]{36}"),             # OAuth app token
    re.compile(r"ghs_[A-Za-z0-9]{36}"),             # App installation token
    re.compile(r"sk-ant-[A-Za-z0-9\-_]{90,}"),      # Anthropic API key
    re.compile(r"Bearer\s+[A-Za-z0-9\-._~+/]{20,}"),# Bearer header value
    re.compile(r"AKIA[0-9A-Z]{16}"),                # AWS access key
]

def _redact_secrets(text: str) -> str:
    for pattern in _SECRET_PATTERNS:
        text = pattern.sub("[REDACTED]", text)
    return text
```

Add to `BackendEvent`:

```python
@model_validator(mode="before")
@classmethod
def _redact_sensitive_detail(cls, data: dict) -> dict:
    if isinstance(data, dict) and "detail" in data:
        data["detail"] = _redact_secrets(str(data["detail"]))
    return data
```

### Test coverage targets
