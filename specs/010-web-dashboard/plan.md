# Implementation Plan: Live Web Dashboard

**Branch**: `010-web-dashboard` | **Date**: 2026-03-02 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/010-web-dashboard/spec.md`

## Summary

Add a live web dashboard served by the coordinare daemon on a configurable port (default 8090). The dashboard displays current workflow phase, active card details, agent session, subsystem health, key metrics, and recent cycle history. State updates are pushed to open browser tabs via Server-Sent Events within 5 seconds of any change. No new Python dependencies — SSE via Starlette `StreamingResponse`, inline HTML served as a string constant, zero npm.

## Technical Context

#### 1b. `SSEBroadcaster`

```python
import asyncio

class SSEBroadcaster:
    def __init__(self) -> None:
        self._queues: set[asyncio.Queue[dict | None]] = set()

    def subscribe(self) -> asyncio.Queue[dict | None]:
        q: asyncio.Queue[dict | None] = asyncio.Queue(maxsize=32)
        self._queues.add(q)
        return q

    def unsubscribe(self, q: asyncio.Queue[dict | None]) -> None:
        self._queues.discard(q)

    def broadcast(self, payload: dict) -> None:
        for q in list(self._queues):   # snapshot prevents RuntimeError on concurrent disconnect
            try:
                q.put_nowait(payload)
            except asyncio.QueueFull:
                pass                   # slow client — drop silently
```

#### 1c. `DashboardStore`

```python
from collections import deque
from datetime import UTC, datetime
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from coordinare.daemon import CoordinareDaemon
    from coordinare.metrics import CoordinareMetrics
    from coordinare.observability import HealthRegistry


class DashboardStore:
    def __init__(self) -> None:
        self.broadcaster = SSEBroadcaster()
        self.history: deque[dict] = deque(maxlen=20)

    def record_cycle(
        self, *, duration_seconds: float, phase: str, outcome: str
    ) -> None:
        self.history.appendleft({
            "timestamp": datetime.now(UTC).isoformat(),
            "phase": phase,
            "duration_seconds": round(duration_seconds, 3),
            "outcome": outcome,
        })

    def build_snapshot(
        self,
        daemon: "CoordinareDaemon",
        metrics: "CoordinareMetrics",
        health: "HealthRegistry",
    ) -> dict:
        snapshot = (
            daemon.state_store.last_snapshot
            if daemon.state_store is not None
            else None
        )
        phase = snapshot.phase if snapshot else daemon.state.get("phase", "idle")

        # subsystems
        health_report = health.snapshot()
        subsystems = [
            {
                "name": p.subsystem_name,
                "status": p.status.value,
                "required": p.is_required,
                "checked_at": p.checked_at.isoformat(),
                "details": p.details,
            }
            for p in health_report.probes
        ]

        # metrics — read prometheus counter value
        cycles_completed = int(metrics.cycles_completed_total._value.get())  # noqa: SLF001

        # last cycle duration from histogram sum/count
        hist = metrics.cycle_duration_seconds
        count = hist._count.get()  # noqa: SLF001
        last_duration = (hist._sum.get() / count) if count > 0 else None  # noqa: SLF001

        error_count = daemon.state.get("error_count", 0)

        # daemon start time from build_info
        started_at = metrics.build_info._labelnames  # sentinel; real value below
        try:
            started_at = metrics.build_info.labels()._value.get().get("started_at")
        except Exception:
            started_at = None

        return {
            "phase": phase,
            "phase_label": format_phase_label(str(phase)),
            "active_card_title": snapshot.active_card_title if snapshot else None,
            "active_card_column": snapshot.active_card_column if snapshot else None,
            "pr_url": snapshot.pr_url if snapshot else None,
            "agent_session_id": snapshot.agent_session_id if snapshot else None,
            "open_questions": list(snapshot.open_questions) if snapshot else [],
            "subsystems": subsystems,
            "cycles_completed": cycles_completed,
            "last_cycle_duration_seconds": last_duration,
            "error_count_since_start": int(error_count),
            "daemon_start_time": started_at,
            "cycle_history": list(self.history),
        }
```

**Note on prometheus internals**: The `_value` / `_sum` / `_count` private attrs are stable across prometheus-client 0.x; document in code why they're used (no public API for reading counter values). If this proves brittle, store cycle count in a plain `int` alongside the deque.

#### 1d. `create_dashboard_app(store, daemon, metrics, health) -> FastAPI`

```python
import json
import time
import uuid
from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse, StreamingResponse
import structlog

_log = structlog.get_logger(__name__)

_DASHBOARD_HTML = """<!DOCTYPE html>..."""   # see HTML design notes below

def create_dashboard_app(
    store: DashboardStore,
    daemon: "CoordinareDaemon",
    metrics: "CoordinareMetrics",
    health: "HealthRegistry",
) -> FastAPI:
    app = FastAPI(title="coordinare-dashboard")

    @app.middleware("http")
    async def _log_requests(request: Request, call_next):
        t0 = time.perf_counter()
        response = await call_next(request)
        elapsed_ms = (time.perf_counter() - t0) * 1000
        is_sse = request.url.path == "/events"
        _log.info(
            "http_request",
            method=request.method,
            path=str(request.url.path),
            status_code=response.status_code,
            response_time_ms=round(elapsed_ms, 2),
            **({"streaming": True} if is_sse else {}),
        )
        return response

    @app.get("/", response_class=HTMLResponse)
    async def dashboard():
        return HTMLResponse(_DASHBOARD_HTML)

    @app.get("/events")
    async def sse_events():
        async def _generate():
            q = store.broadcaster.subscribe()
            try:
                # Send current state immediately on connect
                snapshot = store.build_snapshot(daemon, metrics, health)
                yield f"event: state_update\ndata: {json.dumps(snapshot)}\n\n"
                while True:
                    try:
                        payload = await asyncio.wait_for(q.get(), timeout=15.0)
                        yield f"event: state_update\ndata: {json.dumps(payload)}\n\n"
                    except asyncio.TimeoutError:
                        yield ": keepalive\n\n"
            finally:
                store.broadcaster.unsubscribe(q)

        return StreamingResponse(_generate(), media_type="text/event-stream")

    return app
```

#### 1e. HTML Design

The `_DASHBOARD_HTML` constant is a complete, self-contained HTML document with:
- Inline CSS (no external stylesheet)
- Inline JavaScript (no external library)
- Uses `EventSource('/events')` to connect on page load
- `onmessage` (for `state_update` events): parse JSON, update DOM
- `onerror`: show `#disconnected-banner`
- `onopen`: hide `#disconnected-banner`

Sections rendered via DOM manipulation:
1. **Phase** — large text with colour coding (idle=grey, dispatching/monitoring=blue, blocked=orange, merging=green)
2. **Active Card** — title, column badge, PR link; or "No active card" when null
3. **Agent Session** — session ID or hidden
4. **Open Questions** — unordered list; hidden unless phase=blocked
5. **Subsystems** — table with status badges (healthy=green, degraded=amber, unavailable=red)
6. **Metrics** — counters: cycles completed, last cycle duration, error count, daemon start time (prominent)
7. **Cycle History** — recent entries table; empty-state message when list empty
8. **Disconnected Banner** — fixed overlay, hidden by default, shown on `onerror`

2. **Port conflict detection** — attempt to bind dashboard port before starting uvicorn servers:

```python
import socket, sys

def _check_port_available(host: str, port: int) -> None:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        try:
            s.bind((host, port))
        except OSError as exc:
            logger.error(
                "dashboard_port_conflict",
                host=host,
                port=port,
                error=str(exc),
            )
            sys.exit(1)
```

3. **Create and serve dashboard app** alongside health app:

```python
dashboard_app = create_dashboard_app(
    dashboard_store, daemon, METRICS, HEALTH

dashboard_server = uvicorn.Server(
    uvicorn.Config(
        dashboard_app,
        host=config.dashboard_host,
        port=config.dashboard_port,
        log_level="warning",
    )

dashboard_task = asyncio.create_task(dashboard_server.serve())
```

4. **Broadcast after each cycle** — hook into the daemon's cycle completion. Two options:
   - **Option A (preferred)**: Pass `dashboard_store` to `CoordinareDaemon` and call `store.record_cycle()` + `store.broadcaster.broadcast()` after `ainvoke` in `daemon.py`. This keeps the broadcast call co-located with the cycle timer.
   - **Option B**: Subclass `CoordinareDaemon` to override `start()`. More complex. Rejected.

   Implement Option A: add `dashboard_store: DashboardStore | None = None` parameter to `CoordinareDaemon.__init__`. After `ainvoke` and metric updates, call:

```python
if self._dashboard_store is not None:
    self._dashboard_store.record_cycle(
        duration_seconds=_cycle_elapsed,
        phase=str(self._state.get("phase", "idle")),
        outcome="success",
    )
    snapshot = self._dashboard_store.build_snapshot(self, METRICS, HEALTH)
    self._dashboard_store.broadcast(snapshot)
```

   In the `except Exception` handler, also call `record_cycle(... outcome="error")` and broadcast.

5. **Log dashboard_started** at startup after port check succeeds.

6. **Clean shutdown**: add `dashboard_server.should_exit = True` and `await dashboard_task` to the `finally` block alongside the health server.

## Key Implementation Notes

### Prometheus counter reading

`METRICS.cycles_completed_total._value.get()` uses a private API. If tests mock `METRICS`, ensure the mock exposes a compatible `_value.get()` method, or extract a helper:

```python
def _read_counter(counter) -> int:
    return int(counter._value.get())
```

Alternative: maintain a plain `int` counter on `DashboardStore` and increment it from the daemon. More explicit, less fragile. Preferred if the prometheus private API proves annoying in tests.

### `last_cycle_duration_seconds`

Prometheus histograms expose `_sum` and `_count`. The average `_sum / _count` is accurate but will undercount individual cycles if the histogram is shared. Alternatively, store the last duration as a plain `float | None` on `DashboardStore` and update it from the daemon. This is simpler for testing.

**Decision**: Store `last_cycle_duration: float | None` on `DashboardStore`; update alongside `record_cycle()`. Do not read prometheus internals in `build_snapshot()`.

### Daemon dependency on dashboard

`CoordinareDaemon` will accept `dashboard_store: DashboardStore | None` — this is a one-way optional dependency (daemon → store). The store does not depend on the daemon at construction; `build_snapshot()` receives the daemon as a parameter call-time.

This avoids circular imports: `dashboard.py` uses `TYPE_CHECKING` guards for the daemon type annotation.

### HTML page size

Keep `_DASHBOARD_HTML` under 15 KB. No external resources (no fonts, no icons from CDNs). Plain monospace font acceptable for MVP.
